气海无涯 WeChat News
=====================

**wechat-news** 是“气海无涯”科研资讯微信公众号自动化工具。它通过 QQ Bot
提供科研新闻与正式论文候选，完成内容处理、图片与版权检查、qihai 排版，并将
文章创建到微信公众号草稿箱。

.. important::

   本项目只自动创建微信公众号草稿，不会自动正式发布文章。
